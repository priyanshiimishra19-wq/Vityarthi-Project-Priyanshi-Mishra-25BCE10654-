**LANGUAGE TRANSLATOR**

A simple and efficient command line translator that lets you convert text,batches or entire files into any language using google translator.
It's lightweight and begginer friendly for quick translations


**FEATURES**:
1. Basic Translation-Translate a single line of text into any supported language
2. Batch Translation-Translate multiple lines at once
3. Smart Language Detection-Automatically identifies the source language before translation
4. Lightweight and fast- No heavy dependencies,quick installation and fast execution
5. Translation History Tracking-Stores all translations performed in the session for later viewing

**Project Structure:**

Since this project is small all logic is inside a single python file

**Technologies / Tools Used:**

 1. Python 3.7+
  ,googletrans==4.0.0-rc1

 2. Install dependency: pip install googletrans==4.0.0-rc1

**Steps to Install & Run the Project**
1. Install Python latest version
2. Install Required Python Package-The project uses googletrans library, pip install googletrans==4.0.0-rc1
3. Save the project Code
4. Run the program
