1. Problem Statement

Language barriers often make it difficult for users to understand or communicate information effectively. Existing translation tools are web-based and require continuous internet acces or are not easily customisable.
This project aims to provide a simple, interactive, and efficient command-line translation tool that can translate text, detect languages, and maintain translation history all within a lightweight Python application.

2. Scope of the Project

This project focuses on building a Python-based text translation utility that:
Performs real-time text translation using Google Translate API wrapper.
Supports multiple languages.
Allows users to detect languages.
Maintains a translation history within the session.
Provides a clean menu-driven CLI interface for ease of use.
It does not include advanced NLP processing, GUI applications, offline translations, or file format translations beyond plain text.

3. Target Users
This project is intended for:
Students who need quick translations while studying.
Beginners in Python who want to understand API usage and menu-driven programs.
Developers looking for a lightweight translation tool
Travelers who need simple text translations.
Anyone who prefers using a CLI instead of online translators.

4. High-Level Features
Basic Text Translation
Translate any sentence or paragraph between supported languages.
Language Detection
Automaticaly detect the language of an input string.
Supported Languages List
View all available language codes directly in the program.
Translation History
View all translations done during the session with source and target languages.
Interactive Menu System
Simple, easy-to-navigate command-line interface.
